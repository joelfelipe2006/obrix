# Mockups originais

Esta pasta vai receber os mockups originais do documento do Projeto Integrador (PI),
que antecederam a implementação.

Ainda não foram anexados. Quando a equipe enviá-los:

1. salve cada imagem aqui, com o nome da tela (por exemplo, `W06-painel-cliente.png`,
   seguindo a numeração W/M do documento, citada nos comentários dos scripts de
   `static/js`);
2. registre a origem (seção e página do documento do PI);
3. atualize [../../prototipos.md](../../prototipos.md) com a comparação entre o original e o
   implementado.
