## Descrição

Habilita a carga de dados de demonstração também no perfil `demo`, de forma idempotente (só insere se o cliente de demonstração não existir, numa única transação), para rodar a aplicação com os perfis `prod,demo` contra um PostgreSQL na nuvem (Neon). Documenta as variáveis `OBRIX_DB_*` e a subida.

## Justificativa

Permitir demonstrar o sistema com um banco PostgreSQL hospedado, com dados de exemplo, sem duplicar a carga a cada reinício.

## Análise de impacto

- **Módulos:** Carga de dados de demonstração.
- **Riscos:** Baixos: o perfil `prod` sozinho não ativa a carga. Risco residual: ativar `demo` num banco real inseriria dados fictícios.
- **Esforço:** Baixo (3 arquivos).
- **Testes necessários:** Suíte completa. A idempotência não tem teste automatizado.
