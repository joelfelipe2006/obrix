## Descrição

Instituir o processo de gerência de configuração: modelos de Change Request e de pull request no GitHub, workflow de CI de regressão (`mvn -B clean test` e `node --test`, com o relatório do JaCoCo como artifact), documentação em `docs/mcs/` (processo, CCB, itens de configuração, baselines e registro de CRs), registro retroativo dos CRs a partir do histórico do git e as tags das baselines `v0.1.0`, `v0.2.0` e `v0.3.0`.

## Justificativa

Requisito de avaliação da disciplina e controle real das mudanças: até aqui as mudanças entravam sem registro, sem decisão formal e, em parte, sem pull request.

## Itens de configuração afetados

- IC-19 Documentação de gerência de configuração (novo)
- IC-20 Modelos e CI do GitHub (novo)
- IC-17 README

## Análise de impacto

- **Módulos:** Processo e repositório. Nenhum código de produção alterado.
- **Riscos:** Baixos: o CI pode falhar por diferença de ambiente (versão do Node, cache do Maven), o que bloqueia merges até ser corrigido.
- **Esforço:** Médio.
- **Testes necessários:** Execução do workflow de CI no próprio pull request desta mudança.
